# Weights Directory

Place your YOLOP model weights (.pth files) in this directory.

## Expected files:
- 06_27.pth (default for yolop_lane_detection.launch.py)
- epoch-216.pth (default for lane_IPM.launch.py)
- final_state.pth (default for lane_depth.launch.py)

You can specify custom weight paths using launch file arguments.
